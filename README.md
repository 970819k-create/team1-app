# 인터뷰 브리프 — 기업 자료 기반 AI 영어 면접 준비 (MVP)

지원할 회사의 **채용공고와 기업 자료**를 넣으면, 핵심을 한글·영어로 정리하고, 그 자료로 만든 영어 면접 질문으로
**질문별 연습**과 **AI 면접관과의 실전 시뮬레이션**을 한 뒤, 필요한 표현과 질문을 **복습**하는 웹앱입니다.

## 바로 실행하기

필요한 것: Node.js 20.12 이상

```bash
cd interview-prep
npm install
npm start
```

브라우저에서 **http://localhost:3000** 을 엽니다. 음성으로 답하려면 **Chrome 또는 Edge**를 권장합니다.

### AI 연결 (오른쪽 위 [설정])

앱 화면의 **[설정]**에서 쓸 AI를 고르고 키를 넣습니다. 키를 저장할 때 실제로 연결되는지 확인하고, 언제든 바꾸거나 지울 수 있습니다.

- 키는 **각자의 브라우저에만** 저장됩니다. 서버에는 저장되지 않고, AI를 부를 때마다 그 요청에만 함께 보냅니다.
- 그래서 한 사람이 서버를 켜고 팀원들이 접속해도, **팀원마다 자기 키와 자기가 고른 AI**를 씁니다.
- 서버를 켠 사람이 `.env`에 키를 넣어 두면 키가 없는 사람도 쓸 수 있는 **공용 키**가 됩니다 (`.env.example` 참고, 선택 사항).
- 다른 컴퓨터에서 서버에 접속해 쓸 때는 키가 네트워크로 전달되니, 인터넷에 공개할 때는 HTTPS로 운영하세요.

| AI | 키 받는 곳 | 기본 모델 | 특징 |
|---|---|---|---|
| Claude (Anthropic) | console.anthropic.com → API Keys (`sk-ant-...`) | `claude-opus-5-5` | 품질이 가장 좋음, 유료 |
| OpenAI (ChatGPT) | platform.openai.com/api-keys (`sk-...`) | `gpt-4.1-mini` | 유료 (ChatGPT 구독과 별개) |
| Google Gemini | aistudio.google.com/apikey | `gemini-2.5-flash` | 무료 사용량 있음 |
| Hugging Face | huggingface.co/settings/tokens (`hf_...`) | `openai/gpt-oss-120b` | 공개 모델, 매달 소량 무료. 토큰 권한에 "Inference Providers 호출" 필요. 설정 화면에서 추천 모델(GLM-5.3, Llama-3.3-70B 등)을 눌러 바꿀 수 있음 |
| Ollama (내 PC) | 키 없음. ollama.com에서 설치 후 `ollama pull qwen2.5:7b` | `qwen2.5:7b` | 완전 무료·오프라인, 메모리 8GB 이상 필요, 품질은 낮을 수 있음 |

모델 이름은 각 카드의 [모델] 칸에서 바꿀 수 있습니다. Hugging Face의 GGUF 모델은 `ollama pull hf.co/사용자/모델` 형식으로 Ollama에 받아 쓸 수 있습니다.

**AI가 없어도** 처음 화면의 **[샘플로 체험하기]**로 가상 기업 자료를 불러와 분석 → 질문별 연습 → 실전 면접 → 결과 → 복습까지
전체 흐름을 써 볼 수 있습니다. 피드백과 면접관 대화는 규칙 기반 '기본 피드백'으로 동작합니다(화면에 'AI 미연결'로 표시).

### 면접관 목소리 (선택)

기본은 브라우저 내장 음성입니다. 더 자연스러운 목소리를 원하면 Piper를 설치하세요.

```bash
pip install piper-tts
mkdir -p voices && cd voices
curl -L -O https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_US/ryan/medium/en_US-ryan-medium.onnx
curl -L -O https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_US/ryan/medium/en_US-ryan-medium.onnx.json
```

서버를 다시 켜면 `면접관 음성: Piper 음성 사용`으로 바뀝니다.

### 자동 점검

```bash
npm test
```

서버를 따로 띄워 화면 파일, API, AI 미연결 시 기본 동작, 보안 차단(폴더 밖 파일, 다른 사이트의 설정 변경)을 확인합니다.
`.env`의 실제 키는 쓰지 않으므로 요금이 들지 않습니다.

## 화면 (PRD 4장)

| 화면 | 주소 | 내용 |
|---|---|---|
| ① 자료 입력 | `#home` | 공고 링크/텍스트(필수), 기업 자료 링크/텍스트(최대 4개), 직무명·내 경험(선택), 분석 시작, 내 준비 목록·삭제, 샘플 체험 |
| ② 분석 결과 | `#p/<id>` | 핵심 요약·주요 업무·요구 역량·기업 동향·연결 포인트를 한글/영어/함께 보기로, **확인되지 않음** 목록, 예상 질문, 면접 표현 저장, 모든 항목에 근거 자료(S1, S2…) 표시 → 누르면 원문 확인 |
| ③ 질문별 연습 | `#practice/<id>/<질문>` | 질문 듣기(텍스트 가리기 가능), 음성 답변 → 인식 텍스트 수정, 잘한 점·개선 표현·구조 팁·답변 예시(참고용, [자리 표시자]), 같은 질문 다시 답하기, 답변 기록 |
| ③ 실전 시뮬레이션 | `#interview/<id>` | 면접방: 면접관 발화·답변 상태·마이크 상태·경과 시간·질문 수·종료 버튼·질문 텍스트 보기 선택. 답변에 따라 **후속 질문(메인 질문마다 최대 1회)** 또는 다음 질문. 면접 중 피드백 없음 |
| ③ 면접 결과 | `#result/<id>/<면접>` | 총평, 질문·답변 기록, 질문별 개선 표현과 답변 예시, 표현·질문 저장, 참고 자료 |
| ④ 나의 복습 | `#review` | 저장한 표현(뜻 떠올리기, 예문 빈칸 채우기), 저장한 질문 다시 연습, 학습 기록, 데이터 삭제 |

## PRD 6장 MVP 완성 기준 대응

| # | 기준 | 구현 |
|---|---|---|
| 1 | 링크 또는 텍스트로 입력 | 항목마다 [링크 / 텍스트 직접 입력] 전환 |
| 2 | 출처가 표시된 한글·영어 분석 | 모든 항목에 S1·S2 근거 칩 → 원문 보기 |
| 3 | 영어 면접 질문 3개 이상 | 분석 때 5~6개 생성 (지원 동기·직무 적합·경험·기업 이해·협업) |
| 4 | 질문별 연습: 음성 답변, 변환 텍스트, 예시·피드백 | Web Speech API → 수정 가능한 텍스트 → 피드백 |
| 5 | 실전 시뮬레이션: 음성 연속 대화 | 면접관 음성 → 자동으로 마이크 켜짐 → [답변 완료] → 후속/다음 질문 |
| 6 | 종료 후 기록·예시·개선 표현 | 결과 화면 |
| 7 | 표현·질문 저장과 복습 | ☆ 저장 → 나의 복습 |
| 8 | 읽을 수 없는 링크·자료 부족·마이크 오류·인식 실패 안내 | 링크별 상태와 이유, 텍스트 입력 칸 자동 열기 / 마이크 권한·장치·네트워크 오류 안내 / 인식 실패 시 다시 말하기·키보드 입력 |
| 9 | 없는 경력·기업 사실을 사실처럼 제시하지 않음 | 프롬프트 원칙 + 자료 밖 정보는 '확인되지 않음', 개인 경험은 [자리 표시자] |

## 데이터 처리 (PRD 5장)

- 자료, 분석 결과, 답변 텍스트, 저장한 표현·질문, 학습 기록, **AI 키**는 **브라우저(localStorage)에만** 저장됩니다. 로그인은 없습니다.
- 회사별 삭제(처음 화면의 🗑), 표현·질문 개별 삭제, 전체 삭제(나의 복습 > 학습 기록·데이터)를 할 수 있습니다.
- 분석·피드백·면접 진행 시 자료와 답변 텍스트가 **[설정]에서 고른 AI 제공자**로 전송됩니다 (Ollama는 내 PC 안에서만 처리).
- **음성 원본은 저장하지 않습니다.** 음성 인식은 브라우저 기능을 쓰며, Chrome은 인식을 위해 음성을 Google 서버로 보낼 수 있습니다.
- 학습 이벤트(분석 완료, 연습 답변·재답변, 시뮬레이션 시작·완료, 표현 저장, 복습 완료)를 브라우저에 기록하고 '학습 기록' 탭에서 보여 줍니다. (PRD 7장 지표 검증용)

## 기술 구성

```
server.js              로컬 서버 (정적 파일 + API), 포트 3000
lib/ai.js              프롬프트·결과 스키마, 고른 AI로 호출 (Claude는 구조화 출력 + 서버 측 거절 대비 fallbacks)
lib/providers.js       OpenAI·Gemini·Hugging Face·Ollama 호출과 키 확인 (JSON 결과를 스키마로 검사, 어긋나면 1회 재요청)
lib/settings.js        [설정] 화면의 제공자 목록과 키 확인 (키는 브라우저에만 저장, 요청마다 X-AI-Config 헤더로 받음)
lib/basic.js           API 키가 없을 때 쓰는 규칙 기반 피드백·면접 진행
lib/fetch-source.js    링크 본문 읽기 (내부망 주소 차단, 실패 이유 안내)
lib/tts.js             Piper 음성 합성 (있을 때만)
samples/               샘플 프로젝트 (가상 기업 자료)
public/                화면 (HTML·CSS·JS 모듈, 빌드 없음)
```

- Claude를 고르면 분석·피드백·결과는 effort `medium`, 면접 중 다음 발화는 대기 시간을 줄이려고 `low`로 호출합니다.
- 서버 측 거절 대비(`fallbacks: "default"`)를 켜 두었습니다. 요청이 안전 분류기에 걸리면 API가 다른 모델로 다시 시도합니다. 끄려면 `lib/ai.js`에서 `betas`와 `fallbacks` 두 줄을 지우세요.

## 알아 둘 점

- **링크 읽기 한계:** 로그인이 필요한 공고(LinkedIn 등)나 화면을 자바스크립트로 그리는 채용 사이트는 본문을 읽지 못할 수 있습니다. 이때 앱이 이유를 알려 주고 텍스트 입력 칸을 열어 줍니다.
- **답변 끝 인식:** 실전 면접에서 답변이 끝난 시점은 [답변 완료] 버튼으로 정합니다. 자동 감지는 MVP에서 하지 않았습니다(PRD 8장 가정 6).
- **음성 인식:** Firefox는 지원하지 않아 키보드로 답합니다. 이어폰을 쓰면 면접관 목소리가 다시 인식되는 일을 막을 수 있습니다.
